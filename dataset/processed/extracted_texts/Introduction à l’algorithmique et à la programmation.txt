TypeError : types incompatibles
I
Certains types sont incompatibles : on ne peut pas les
mélanger dans une même opération;
I
Quand ce problème survient, Python provoque une
exception de type TypeError;
I
Cela a pour effet d’arrêter le programme;
Exemple
>>> '3' * 2 # ok
'33'
>>> '3' + 2 # erreur!
Traceback (most recent call last):
File "<stdin>", line 1, in <module>
TypeError: Can't convert 'int' object to str implicitly
I
Si une variable n’a pas le bon type, vous devez la convertir
(transtypage);
